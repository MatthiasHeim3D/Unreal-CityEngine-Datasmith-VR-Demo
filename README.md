CityEngine -> DataSmith -> Unreal Engine VR Demo

## Overview 
It showcases how to take 3D models created in *Esri CityEngine* and integrate them into an *Unreal Engine* VR project using *Datasmith*. The end result is a fully interactive VR environment featuring large-scale urban environments.

## Requirements
- **Unreal Engine 5.5** (or higher)  
- **VR Hardware** compatible with Unreal’s *OpenXR* (e.g., HTC Vive, Oculus Rift, etc.)  
- **Esri CityEngine** for creating and exporting the city models  
- **Datasmith Plugin** for Unreal Engine  

## Installation
1. **Clone or download** this repository to your local machine.  
2. **Open** Unreal Engine 5.5 (or higher).  
3. **Enable Datasmith** under `Plugins` if it is not already enabled.
